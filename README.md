# PWA - Storia della lingua italiana

Applicazione web installabile e offline, costruita a partire dalle micro-lezioni integrali in Markdown.

## Contenuto
- 31 micro-lezioni
- testo originale integrale
- immagini originali di ogni pagina
- manifest e service worker per uso offline

## Avvio locale
Apri `index.html` con un server statico oppure pubblica la cartella su GitHub Pages.
